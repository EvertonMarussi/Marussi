# Portfolio photography

Add the owner's approved assets here. Configure the relative filenames in `src/data/portfolio.js`.

- Portrait: `portrait.webp`, recommended 1200 × 1500, subject centered, head and shoulders visible. Set `portrait: 'images/portrait.webp'`.
- Smart Outlet: project/prototype photo, recommended 1400 × 1000.
- Battery prediction: an approved chart or research screenshot, recommended 1400 × 1000. Do not invent model metrics.
- Corporate systems: approved product screenshot without confidential information, recommended 1400 × 1000.

Empty values show intentional reserved spaces. No stock person is presented as Everton.
